# Scale tiers
| Tier | Example | Roles spawned | Concurrency | Milestones | Review |
|---|---|---|---|---|---|
| jam | one-screen arcade, 1 day | producer, designer-dev, artist/audio combo, qa | 2-3 | Playable → Polish | qa spot-check |
| mobile | hypercasual / puzzle | + ui-programmer, audio, build | 3-4 | Proto → Vertical slice → Soft-launch build | qa every ticket |
| indie | 2D/3D game, hours of content | all core roles, writer if narrative | 4-6 | Pre-prod → VS → Alpha → Beta → Release | qa + tech-lead code review |
| aa | multi-system 3D | + engine prog, tech-artist, team leads | 6-8 | + content lock, perf pass | lead per team + qa |
| aaa | large 3D, many systems | per-pillar teams (combat, world, UI, narrative, tools) with leads | ≤ 8 per wave, many waves | + cert-style QA, perf/memory budgets | lead + qa; tech-lead signs architecture |

Rules at every size:
- Ticket = one worker-session. Bigger → split into an epic.
- Vertical slice before content breadth. Graybox before art.
- AAA honesty: agents can build systems, pipelines, prototypes and vertical slices; full AAA content volume takes many milestones. Tell Boss the realistic plan up front; keep every milestone playable.
- Leads review their domain; Producer doesn't review code when a lead exists.
